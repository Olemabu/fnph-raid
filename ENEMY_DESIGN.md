# Mecha answer targets — v1.2.6
Built-in image_gen generated the enemy hull using src/assets/kestrel-hangar.webp as a material/detail reference. Player artwork is unchanged. Final bundled alpha asset: src/assets/enemy-mecha-v1.webp. The generated PNG was converted to WebP and resized for runtime use; transparency is retained.

Production prompt: One enemy hovering armoured drone viewed orthographically from directly above, nose toward bottom, symmetrical broad silhouette. Match the reference aircraft's realistic hard-surface mecha detail, worn ivory panels, graphite metal, brass machinery and exposed pistons. A large empty dark rectangular recessed display is reserved for real answer text. Substantial layered armour, rivets, turbine pods and cannon housings surround the display; restrained burgundy optics and orange engines distinguish an enemy. No cartoon UFO dome, pink neon, UI, numbers, letters or watermark. Transparent background, full hull visible.

Nine-slice rendering expands the empty display while keeping actual armour art at readable dimensions. The DOM answer region overlays only the recessed screen (14–86% width, 27–80% height). The whole craft remains the existing swept-shot target; no additional numbered target exists underneath. Aimed craft get small display-corner brackets, and armour indicators sit on the hull. Long answers retain their full text and can be swiped or scrolled when the aircraft is underneath their lane. Font remains 11 px on phone; desktop uses 13 px. Both Python and PowerShell builders embed the asset for web/offline/APK use.
